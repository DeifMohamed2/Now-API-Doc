Now Shipping Public API v1 gives engineering teams a single REST interface to embed courier logistics into any e-commerce platform or SaaS product operating in Cairo, Giza, and Qalyubia. All fees are computed server-side, zones are validated against the delivery catalog, and multi-tenant company integrators can manage unlimited merchant sub-accounts with one API key.

## End-to-end workflow

<Steps>
  <Step title="Get your API key">
    A Now Shipping admin creates your API key under **Admin → Business details → API Access**. Copy it immediately — it is shown only once.
  </Step>
  <Step title="Load the delivery zone catalog">
    Call `GET /delivery-zones` and cache the response. All order zones must be exact `value` strings from this catalog.
  </Step>
  <Step title="Onboard your first merchant">
    For company integrators, call `POST /merchants` to create a ready-to-ship sub-account. Save the returned `businessAccountCode`.
  </Step>
  <Step title="Create an order and download the AWB">
    Call `POST /orders` with `X-Merchant-Id`, then fetch the shipping label PDF via `GET /orders/{orderNumber}/awb`.
  </Step>
</Steps>

<Note>
**Base URL:** `https://now.com.eg/api/public/v1`

All endpoints require an `Authorization: Bearer nsk_live_YOUR_KEY` header except `/docs` and `/openapi.yaml`.
</Note>
